L’application ÉCHELLE EG39 n’est pas encore publiée sur Google Play ni sur l’App Store. Cette page distribue la version de test pour Android. Elle est signée et identique à la version qui sera publiée.

Télécharger l’application

Version 1.0.0 · 61 Mo · Android 7.0 (API 24) · aucun compte de magasin requis

Connexion mobile limitée : variante allégée (23 Mo), pour un téléphone Android récent. Même application.

Installation sur Android

  1. Touchez Télécharger l’application ci-dessus. Le fichier arrive dans les téléchargements du téléphone.
  2. Ouvrez le fichier téléchargé. Android prévient que l’application ne vient pas du Play Store : c’est attendu à ce stade.
  3. Autorisez l’installation quand Android le demande (Installer des applications inconnues, pour Chrome ou Fichiers). L’autorisation vaut pour cette source une fois pour toutes.
  4. Ouvrez ÉCHELLE EG39 et connectez-vous avec votre compte.
Mise à jour : une nouvelle version se réinstalle de la même façon, par-dessus l’ancienne. Vos données et votre session sont conservées. Hors magasin, l’application ne se met pas à jour toute seule.

Il n’y a pas encore de lien de test pour iPhone. Apple n’autorise l’installation que de paquets signés, et la diffusion par TestFlight suppose un compte développeur Apple payant. Écrivez à admin@echelle-eg39.com pour être prévenu dès que le lien iPhone existe.
